GitHub 设置

令牌只保存在此浏览器中，并且只发送给 api.github.com。

如何创建令牌
  1. 打开 GitHub 新建令牌页面。
  2. Repository access → Only select repositories → 选择 Hydrofoooil.github.io。
  3. Permissions → Contents: Read and write。
  4. 选择一个过期时间，生成后粘贴到上方。

令牌只保存在此浏览器中，不会上传到别处。
